## What I'm building

- **[Project SURGE](https://github.com/ssm2006/Project-SURGE)** — Storm Understanding & Resilience Guidance Engine. Cyclone and storm-surge early-warning platform for the Bay of Bengal, built with Google Earth Engine and Gemini for the *Google Code for Communities* track.
- **PackSureAI (SIH26034)** — AI compliance checker that scans package images and validates Legal Metrology declarations. FastAPI + PaddleOCR + Flutter.
- **[EduVistara](https://github.com/ssm2006/Eduvistara_AIForBharat)** — AI-driven education platform (TypeScript, multilingual).

## Selected projects

| Project | What it does | Stack |
|---|---|---|
| **[Project SURGE](https://github.com/ssm2006/Project-SURGE)** | Predictive storm-surge risk and infrastructure cascade modeling | JavaScript, Python, Earth Engine, Gemini |
| **PackSureAI** | Scans packaged-commodity images and checks mandatory Legal Metrology declarations (MRP, net quantity, manufacturer, dates) with confidence scoring and human review | Flutter, FastAPI, PaddleOCR, OpenCV, Firebase |
| **VoteWise** | AI civic-education app for Indian citizens, deployed on Cloud Run | React 19, FastAPI, Gemini API, GCP |
| **[EcoTrack](https://github.com/ssm2006/EcoTrack)** | Carbon-footprint tracker with glassmorphism UI and a 22-test pytest suite, live on Railway | Flask, pytest |
| **[EduVistara](https://github.com/ssm2006/Eduvistara_AIForBharat)** | AI education platform with i18n and Firebase | TypeScript, Firebase, i18next |
